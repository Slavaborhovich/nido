# Nido

**לא רק לנהל את הבית — להרגיש בבית**

אפליקציה משפחתית: היום, משימות, קניות, יומן, רעיונות, סקר שוק, קופונים והוצאות.

| סביבה | כתובת | ענף |
|---|---|---|
| אמיתית | https://slavaborhovich.github.io/nido/ | `main` |
| בדיקה | https://slavaborhovich.github.io/nido/test/ | `test` |

- הנתונים נשמרים ב-Firebase Firestore, לכל משפחה בנפרד (`families/{משפחה}/envs/prod/...`). סביבת הבדיקה (`envs/test/...`) פתוחה רק למשפחה הראשית.
- כניסה עם שם משתמש וסיסמה. אין הרשמה עצמית: מנהל המערכת יוצר משפחות ומשתמשים מתוך מסך הניהול באפליקציה, ומנהל משפחה יכול להוסיף ולמחוק משתמשים במשפחה שלו בלבד.
- תפקידים: מנהל מערכת, מנהל משפחה, עורך, צפייה בלבד.
- כללי האבטחה נמצאים ב-`firestore.rules` ומועלים ידנית ב-Firebase Console (לא נפרסים אוטומטית).
- התראות: שרת חינמי ב-Cloudflare Workers — ראו `push-worker/README.md`.
- התקנה בטלפון: לפתוח את הכתובת ב-Chrome ← ⋮ ← "הוספה למסך הבית".

תהליך עדכון: שינוי נדחף קודם ל-`test` ונבדק, ורק אחרי אישור ממוזג ל-`main`.

אחרי מחיקת משתמש באפליקציה, החשבון שלו נשאר ב-Firebase Authentication (חסום לגמרי — אין לו פרופיל). אפשר למחוק אותו ידנית ב-Console ← Authentication.
